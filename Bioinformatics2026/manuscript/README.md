# LeafletFA — Bioinformatics manuscript (Overleaf-ready)

Main text `leafletfa_main.tex`, supplement `leafletfa_supplement.tex` (OUP authoring template, same class options as the
SpliceVI paper). Build: `latexmk -pdf leafletfa_main.tex` (latexmkrc builds the supplement first for `xr` labels).

- `numbers.tex` is generated by `../paper/scripts/make_numbers_tex.py` from `../paper/ledger/results_ledger.tsv`. Do not edit it.
- To start the Overleaf project from this folder: create an empty Overleaf project, take its git URL, then from the repo root
  `git subtree push --prefix Bioinformatics2026/manuscript <overleaf-git-url> master` (or upload the folder as a zip).
- Figures go in `Figures/` as built by `../paper/figures/make_figures.py`.

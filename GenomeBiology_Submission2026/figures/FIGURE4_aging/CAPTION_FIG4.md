**Supplementary Figure SX. A partially reproducible program.**
A program used mainly by endothelial and smooth-muscle cells is found in all three seeded fits of the
atlas model (K = 20), but its composition agrees only partly between them.
**(a)** Mean activity per tissue–cell type of the matched program in each of the three fits (seed 0
SP4, seed 1 SP6, seed 2 SP8: the programs matched to seed-0 SP4 on centered ψ), for the 20 tissue–cell types that use it most.
**(b)** Centered-ψ cosine between fits for every program in use, with this program highlighted, against the
0.8 threshold used for program-level statements; the four reproduced programs are labeled.
**(c)** The program's top junctions in each fit (largest departure from the π-weighted mean of the other
programs), marking which are shared by all three fits and which are specific to one.
Statements about this program are restricted to what the three fits share (Methods, Program Reproducibility).
